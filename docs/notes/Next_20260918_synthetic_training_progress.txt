Protocol fixed before training
- Seeds: model 918; train placement 31415; holdout placement 92653.
- 32x32 grayscale analytic fixtures: asymmetric two-lobe q1, ellipse q2,
  soft square q4; circle q0 means orientation undefined.
- Train: four angles per q1/q2/q4 plus two circles (14 images).
- Holdout: twelve unseen angles per q1/q2/q4 plus two circles (38 images).
  Angles disjoint modulo each symmetry period. Holdout also changes scale
  (.92/1.08), intensity (.85) and placement. This is a combined controlled
  shift, not an isolated angle-only robustness sweep.
- One instance/image, GT mask and known q supplied. Circle invalidity verifies
  supplied q0 gating; it does not demonstrate learned symmetry classification.
- PoseBranch input1/channels2/K12; Adam .01; full batch; 240 fixed steps.
- Target: softmax(2*cos(q*(bin-theta))); KL objective.
- Train acceptance: final/initial KL <= .35, MAE <= 2 deg, max <= 5 deg,
  no invalid non-circle predictions, both circles angle-invalid.
- Holdout acceptance: MAE <= 1 deg, P95 <= 2 deg, same validity rules.
- Freeze/save final weights before constructing/evaluating holdout. No
  holdout-based model selection, threshold adjustment or early stopping.
- GT geometry generates labels, not another model. PGM files are previews;
  serialized float image/mask tensors are the exact training data.
- Existing output directories refused; no existing test image is modified.

Identified limitation
The independent checker computes the harmonic angle of the ideal target
distribution, without using any learned weights. For K12/q4 the train-label
maximum error is already 5.496837 deg (e.g. 22.5 deg target); holdout ideal
target MAE 4.347233 and max 5.619076 deg.
K12/q4 supplies only three distinct harmonic phases. The sampled exponential
target contains higher harmonics that alias into the decoded moment. K>2q
alone does not make this target-to-moment conversion unbiased.
This explains the dominant train q4 error despite near-zero KL. Other
holdout errors still include learning/rasterization/scale-intensity effects;
do not attribute all model error to this single issue.
