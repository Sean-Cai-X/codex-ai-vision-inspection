Pre-registered design
Same architecture PoseBranch(1,2,12), model seed918, train seed31415,
Adam lr.01, 240 steps, batch14 for every arm. No early stopping or extra steps.
Each arm receives 3,360 image presentations (2,880 oriented, 480 q0 circles).
No added training angles or positions. Original four angles per q1/q2/q4,
two circles, original subpixel placement.
Scale levels .9,1,1.1; intensity levels .8,.9,1.
At step t, sample index i:
  scale level index = (t+i)%3
  intensity level index = (floor(t/3)+i)%3
Only enabled factors vary; disabled factors equal1. Joint arm cycles through
all nine combinations in each complete nine-step cycle. 240 steps are fixed,
so the final partial cycle need not have exactly equal counts.
GT masks are regenerated for scale changes; intensity does not alter masks.
Brightness is synthetic multiplicative dimming only, not arbitrary lighting.

Interpretation
Joint augmentation is the strongest candidate under this fixed, single-seed
development comparison. Scale-only training improves scale sensitivity but
does not solve intensity sensitivity. Intensity-only training is not enough
and worsens some clean-angle results in this run.
These observations support adding both kinds of training coverage before
changing normalization/pooling, but do not prove a universally optimal recipe.
Same optimizer steps and batch size control sample-presentation budget, not
identical wall-clock cost. Different arms necessarily see different images.
No independent acceptance set was accessed or created in this step.
