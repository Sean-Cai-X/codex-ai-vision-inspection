业务隔离推理测试交接：Circle / Ellipse Unified V5
================================================

交付范围
本次提供两个候选包：circle 和 ellipse。不是一个已经联合训练完成的双类模型。
保留固定七类顺序：arc / circle / ellipse / line / open_curve / polygon / closed_curve。
允许 development_trial / isolated_business_validation，仅外部候选推理预览。
禁止生产激活、默认模型替换、候选作为父模型，以及伪造本地训练完成记录。

本次实际完成
真实业务 broker + typed transport + runtime DLL，两个候选各 5 张研发合成图：
3 Train、1 Valid、1 VERIFY，全部通过推理、回执身份、417/417 权重加载检查；
原始与 typed 七类数量一致，错误摘要拒绝、训练禁止、默认会话隔离检查通过。
acceptance/circle.json 和 acceptance/ellipse.json 为真实验收记录；不是 UI 模拟测试。
全部图像来自研发合成；未读取业务原图，未操作业务默认配置或历史模型。

使用顺序
1. 用研发单独发送的集合 handoff.lock.json SHA 核验整个交接目录。
   不得用包内自报摘要充当独立信任来源。
2. 按项目选择 circle 或 ellipse 子目录。external_preview_root 不能指向集合根目录。
   子包各有自己的 handoff.lock.json，摘要在 delivery_index.json 和本文后部。
3. 执行子包 Test-Preview.ps1 的 ValidateOnly，检查已安装依赖 SHA。
   没有捆绑第三方 DLL。缺依赖/版本不符必须阻断，不回退其他 runtime。
   可以用 OutputBase 参数运行完整研发合成重放，不会读取业务图片。
4. 由业务侧从自己的冻结项目创建 SESSION-ONLY bootstrap，不保存为默认配置。
   runtime_library：所选子包 runtime/libtorch_module_runtime.dll。
   expected_runtime_sha256：delivery_index.json 中的本次真实 SHA。
   external_preview_root：所选子包。
   external_preview_lock_sha256：对应子包的独立摘要。
   external_preview_target_manifest_sha256：业务侧对自身冻结项目重新计算。
   model_root 保持业务已登记父模型根；父模型/attestation 摘要必须与交付一致。
   为会话预建 <原输出根>/preview/<子包lock摘要前16位>/isolated_business_validation。
   bootstrap 的 controlled_trial_output_root 指向该 preview 会话根，不是旧输出根。
5. GetCapability 后，对 Train、Valid、VERIFY 分别执行推理。
   核查回执/候选列表/原图叠加一致，记录漏检、错类、多候选和轮廓偏差。
   不将 Train 推理当成独立验证；未标注 VERIFY 不凭空计算 IoU 或漏检率。
6. 外部预览中点击训练应拒绝，不应产生训练任务或候选注册记录。
7. 退出预览会话、重开原配置即回滚；默认候选和已保存配置保持不变。

模型质量的已知限制
研发五图圆目标数：3/1/1/1/1，错误类别数：13/17/9/14/9。
研发五图椭圆目标数：1/1/1/1/1，错误类别数：19/15/18/3/7。
高 IoU 不代表数量和分类合格。全部图触及 NMS 搜索上限，完整 post-NMS 数量未知。
这些问题允许进入隔离工具测试，但不代表效果通过；请不要过滤掉错误类别再验收。
同源合成变体不证明真实业务泛化，真实业务准确率需在业务冻结图集独立评估。

训练边界
候选来自 native unified_v5 实验，40 Epoch / 40 update / batch 2，每 Epoch 1 update。
真实 loss、验证 loss、有效 LR 在 candidate/training_trace.json。
BN 使用训练统计，验证和推理 eval；前后处理保持原父模型设置。
当前 DLL 的业务训练仍为 center_dense_balanced_bce_v2。
本次没有把 unified_v5 接入业务训练 ABI，不允许声称业务再次训练等价于此候选。
