Change: unified_v13_sigmoid_background_experimental
---------------------------------------------------
V12 foreground CE on [0,z0,...,z6] is unchanged. For background anchors replace
CE(background) = log(1 + sum_c exp(z_c)) with sum_c softplus(z_c), i.e. summed
BCE-with-logits against zero targets for all seven emitted sigmoid channels.
L_cls = mean(foreground CE) + mean(background summed BCE)
      + 2*mean(top-K background summed BCE).
K = min(background anchors, max(1,20*positive anchors)), same as v12.
The background sum has a different scale and gradient distribution from CE:
at zero logits it is 7*log(2), versus log(8) for v12. The experiment therefore
includes this intended background-strength change; it does not isolate score
semantics independently of loss scale. Loss magnitudes are not comparable
between these objectives. No statistical confidence-calibration claim is made.
New behavior is opt-in test code only. Production training implementation and
seven-channel sigmoid/class-max/NMS decoder are unchanged.
