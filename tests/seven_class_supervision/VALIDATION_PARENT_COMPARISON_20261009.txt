Conclusions and limits

Model quality NOT accepted. Synthetic same-generator variants are not independent
business accuracy evidence. IoU of the best wrong-class mask is diagnostic only.
The parent already exhibits this classification error: it is not introduced only
by the new two-update trial. The candidate improves the VERIFY mask but does not
correct its class; Train/Valid mask overlap does not uniformly improve.
Fixed class ordering and original 64x64 mask dimensions passed checks. This does
not establish that historical parent training used semantically correct labels.

Code audit
DecodeCandidates takes sigmoid(class_logits).max(class axis), no class-ID offset.
ComputeBusinessYoloV8SegLoss supervises one target-center anchor per feature
level and has no classification penalty on nonselected/background anchors.
This is a confirmed supervision limitation, not yet a proven sole root cause.
Validation uses the same loss; validation_score = 1/(1+loss), not mAP or IoU.
Training mode is correctly restored with model->train() after validation.
