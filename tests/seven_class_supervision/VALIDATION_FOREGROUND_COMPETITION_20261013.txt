Experimental objective (unified_v12_foreground_competition_experimental)
------------------------------------------------------------------------
The only replaced component is classification loss. Seven emitted logits z
are unchanged. For training only, construct [0,z0,...,z6], where the leading
zero is a fixed background reference, NOT a learned eighth class/head.
Assigned anchors get their shared-owner class label + 1; unassigned anchors
get background label 0. Compute per-anchor cross entropy on these eight values.
L_cls = mean(assigned CE) + mean(background CE) + 2*mean(hard background CE).
Hard-background quota = min(background anchors, max(1,20*positive anchors)).
Empty partitions contribute differentiable zero; invalid multi-owner targets
are rejected. Unlike v5, this loss has no focal multiplier and hard mining is
over background ANCHORS, not individual negative class logits. Thus this is a
classification-objective comparison, NOT an isolated positive-CE coefficient
ablation. Absolute total/class/validation losses are NOT comparable to v5.

Inference is deliberately unchanged: seven independent sigmoid outputs,
argmax class, confidence .25, class-agnostic box NMS .45, mask .5, cap 20.
Training softmax probability is not the emitted sigmoid confidence; no claim
of statistically calibrated confidence is made. This experiment tests the
objective with the existing decoder; it does not replace decoder semantics.
